# Landing page — copy pipeline from mined language

**Milestone:** ML — Landing Page · **Area:** site · **Size:** M

## Why
The unfair advantage: once the engine has real data, the site's headlines
use the audience's actual words mined by #006/#010 — not invented marketing.

## Scope
- `site/copy/` pipeline reading exported phrase stats (problem words,
  verbatim quotes) and proposing headline/subhead candidates with provenance
  links back to clusters.
- Human picks; nothing auto-publishes. Ethical line documented: quotes used
  only as internal language research, never displayed as testimonials.

## Acceptance criteria
- [ ] Copy doc maps each headline to its source cluster + example phrases.
- [ ] No fabricated numbers, no fake testimonials anywhere (hard rule).
